# 1. Краткое описание плагина

`dsh-voice-chat` — это **плагин голосового диалога в стиле Doubao** для DeepSeek Harness (DSH) Web GUI. Он добавляет кнопку микрофона рядом с полем ввода чата:

- **Говори**: нажми 🎤 для начала записи, после паузы запись автоматически завершается, речь преобразуется в текст и отправляется AI;
- **Слушай**: ответы AI синтезируются в речь через TTS и озвучиваются (бесплатный Edge TTS с русскими голосами / MiMo TTS / пользовательский TTS / браузерный синтез / офлайновый Piper);
- **Опциональный пересказ**: при включении «сокращения длинных ответов» они сперва сжимаются и пересказываются LLM от лица «самого помощника», а затем озвучиваются;
- **Русский язык** в интерфейсе и по умолчанию для речи; язык и скорость озвучки переключаются в настройках;
- **Офлайн и живой диалог**: локальный движок (faster-whisper + Piper) работает без ключей и сети, а режим «Постоянный диалог» убирает необходимость каждый раз нажимать 🎤.
