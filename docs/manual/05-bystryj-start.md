# 5. Быстрый старт (5 минут)

1. **Обновите страницу** (Ctrl+Shift+R), убедитесь, что справа от поля ввода появилась кнопка 🎤;
2. Настройте движок распознавания (облачному — ключ; браузерному и локальному ключ не нужен, см. [Руководство по настройке(07-nastrojka.md));
3. **Нажмите 🎤** → услышите «динь» → начните говорить;
4. После паузы около 2.5 секунд → услышите «дон» → речь автоматически преобразуется в текст и отправляется;
5. После получения ответа AI **автоматическое озвучивание**.

> 💡 Хотите быстрее? Держите **правый Ctrl** — запись начнётся сама, отпустите клавишу — текст уйдёт в чат (клавишу можно заменить в настройках, см. [6.3(06-ispolzovanie.md#63-клавиша-запуска-распознавания)).
