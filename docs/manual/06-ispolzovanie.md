# 6. Руководство по использованию

### 6.1 Кнопки

| Кнопка | В состоянии покоя | После нажатия | Описание |
|---|---|---|---|
| 🎤 Микрофон | Серый | Становится красным ● запись | Повторное нажатие = завершить и отправить |
| 🔊 Переключатель звука | Серый | Оранжевый при воспроизведении / красный 🔇 при отключении | Нажать во время воспроизведения = немедленно отключить звук; повторное нажатие = восстановить автоматическое озвучивание |
| ⚙️ Доступ к настройкам | Кнопка настроек в левом нижнем углу | Открывает диалог настроек DSH | Категория «voice chat» слева: выбор движков ASR/TTS, настройка API, голосов и т.д.; изменения применяются сразу после сохранения |

### 6.2 Процесс голосового взаимодействия

```
Нажать 🎤 или удерживать клавишу запуска (по умолчанию правый Ctrl) → динь → [Запись…] → говорить → отпустить клавишу (или пауза 2.5 с — можно изменить в настройках)
→ дон → распознавание… → текст вставляется в поле ввода и автоматически отправляется (можно изменить на только вставку)
→ ответ AI → озвучивание (при включенном «пересказе с озвучиванием»: сначала LLM сжимает, от лица помощника, затем озвучивание, по умолчанию выключено)
→ в процессе можно нажать 🔊 для остановки / удерживать клавишу запуска, чтобы перебить озвучку и говорить заново
```

### 6.3 Клавиша запуска распознавания

Действие — **удержание** (push-to-talk): нажали клавишу → запись пошла, отпустили → запись остановилась, запись ушла на распознавание и (по умолчанию) отправилась. Удерживать клавишу удобно большим пальцем, не отпуская мышь; если микрофон уже пишет, нажатие игнорируется, а отпускание завершает запись.

| Что | Как |
|---|---|
| Клавиша по умолчанию | **Правый Ctrl** (`ControlRight`) — не конфликтует с `Ctrl+C` / `Ctrl+V` (левый Ctrl) |
| Смена клавиши | Настройки DSH → голосовой чат → «Клавиша запуска распознавания»: нажмите на поле, затем нужную клавишу или сочетание |
| Сброс | `Esc` в поле или кнопка «Правый Ctrl» |
| Отключить | `Delete` в поле или кнопка «Выключить» (поле покажет «не задана») |
| Где хранится | `asrHotkey` в `settings.local.json` (строки: `ControlRight`, `Ctrl+Shift+Space`, `Ctrl+Alt+M`; пусто — выключено) |

Поддерживаются одиночные модификаторы (левые/правые `Ctrl`, `Shift`, `Alt`, `Cmd`/`Win`), сочетания с ними, буквы, цифры, `Space`, `Enter`, `Tab`, стрелки. Автоповтор при удержании игнорируется, а уход со вкладки во время записи её корректно завершает.

> Старые жёстко зашитые `Ctrl+Shift+Space` и `Ctrl+M` убраны — используйте настраиваемую клавишу.

### 6.4 Индикаторы состояния

- **Звуковые сигналы**: начало «динь» (880 Гц), завершение «дон» (523 Гц), короткие и мягкие;
- **Всплывающие подсказки**: состояния записи/распознавания/ошибок и т.д. кратковременно отображаются над кнопкой;
- **Цвет кнопок**: запись красный, распознавание жёлтый, воспроизведение оранжевый, отключение звука красный.

### 6.5 Постоянный диалог (живое общение)

Включается галочкой «Постоянный диалог» в ⚙️ → голосовой чат → Настройки распознавания речи.
После этого не нужно каждый раз нажимать 🎤:

- **Автопродолжение**: как только AI договорил (озвучивание закончилось), микрофон снова включается сам — можно говорить следующую фразу;
- **Перебивание**: если начать говорить поверх озвучки, AI замолкает на середине и сразу записывается ваша речь (срабатывает после ~0.45 с непрерывного звука, чтобы не реагировать на случайный шум);
- **Автоотправка** в этом режиме всегда включена: если у вас отключена обычная автоотправка, текст всё равно уйдёт сразу — иначе диалог прервётся;
- **Как остановить**: нажать 🎤 ещё раз (цикл не продолжится), нажать 🔊 (выключить звук — цикл тоже не продолжится) или снять галочку в настройках.

Требуется разрешение браузера на микрофон; во время озвучки он открывается вторым потоком только для контроля громкости.
