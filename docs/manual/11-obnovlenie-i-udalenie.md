# 11. Обновление и удаление

```bash
# Обновление этого форка
dsh plugin --profile web add https://github.com/AlekseiShchemelev/dsh-voice-chat-ru.git

# Удаление
dsh plugin --profile web remove dsh-voice-chat
# Затем перезапустите dsh web
```

Русский форк [dsh-voice-chat-ru](https://github.com/AlekseiShchemelev/dsh-voice-chat-ru) от maoyuching ([оригинал](https://github.com/maoyuching/dsh-voice-chat), MIT).
